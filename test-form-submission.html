Test Form Submission

This test will help verify if the form submission is working correctly.

Steps to test:

  1. Open the phonebook application: http://localhost:8080/phonebook/
  2. Click the "Add Contact" button to open the form
  3. Fill in the form:
    • Name: Test User
    • Phone: 123-456-7890
    • Email: test@example.com (optional)
  4. Click the "Save" button
  5. Check if the contact appears in the table
  6. Monitor the server logs for the "TEST METHOD CALLED" message

Expected behavior:

  • The form should submit successfully
  • The addContact method should be called (visible in logs)
  • The contact should appear in the contacts table
  • The form should close after successful submission

If the test fails:

  • Check browser console for JavaScript errors
  • Verify that the f:ajax tag is present on the save button
  • Check if validation is preventing submission
  • Monitor server logs for any error messages
