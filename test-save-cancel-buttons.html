ICEfaces Phonebook - Save and Cancel Button Test

Test Instructions

Open the phonebook application at: http://localhost:8080/phonebook/contacts.xhtml

Test 1: Add Contact Dialog - Save Button

  1. Click "Add Contact" button
  2. Fill in Name: "Test User"
  3. Fill in Phone: "555-1234"
  4. Leave Email empty (optional)
  5. Click "Save" button
  6. Expected: Dialog should close, contact should appear in table, success message should show

Test 2: Add Contact Dialog - Cancel Button

  1. Click "Add Contact" button
  2. Fill in some data (don't save)
  3. Click "Cancel" button
  4. Expected: Dialog should close, no contact added, form should be reset

Test 3: Add Contact Dialog - Validation Error

  1. Click "Add Contact" button
  2. Leave Name field empty
  3. Fill in Phone: "555-5678"
  4. Click "Save" button
  5. Expected: Dialog should stay open, validation error message should show
  6. Fill in Name: "Test User 2"
  7. Click "Save" button
  8. Expected: Dialog should close, contact should be saved

Test 4: Edit Contact Dialog - Save Button

  1. Click "Edit" button on an existing contact
  2. Change the name to "Updated Name"
  3. Click "Save" button
  4. Expected: Dialog should close, contact should be updated in table, success message should show

Test 5: Edit Contact Dialog - Cancel Button

  1. Click "Edit" button on an existing contact
  2. Change some data (don't save)
  3. Click "Cancel" button
  4. Expected: Dialog should close, no changes saved, original data preserved

Key Fixes Applied

  • ✓ Added AJAX handling to Cancel buttons in both Add and Edit dialogs
  • ✓ Fixed render targets for Save buttons to update all necessary components
  • ✓ Improved dialog state management to keep dialogs open on validation errors
  • ✓ Enhanced error handling to preserve dialog state during failures

Technical Details

Changes Made:

  • Add Contact Save Button: Added proper render targets including dialog, messages, table, and contact count
  • Add Contact Cancel Button: Added AJAX with execute="@this" and render="addContactDialog"
  • Edit Contact Cancel Button: Already had AJAX but improved render targets
  • ContactBean: Enhanced addContact() and updateContact() methods to only close dialogs on successful operations
  • Validation: Dialog stays open when validation fails, allowing user to correct errors
